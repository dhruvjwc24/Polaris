# Polaris

An automated B2B sales pipeline for local service businesses. Polaris discovers prospects, auto-generates a fully branded landing-page mockup populated with the prospect's real business data (name, Google reviews, photos), and runs the outreach end to end — so a cold prospect opens their email and sees a finished, working site built specifically for them instead of a generic pitch.

## Demo

[**Watch the demo**](docs/media/demo.mp4) — campaign creation through a generated mockup site (branded hero, services, testimonials, contact form) for a real lead.

## Stack

Next.js 15, React 19, Supabase (Postgres), Google Places API, Anthropic Claude.
